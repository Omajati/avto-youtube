# Авто ютуб — правила для Claude

## Каждое изменение сразу выпускается как новая версия

Владелец обновляет программу кнопкой «Проверить обновления». Программа читает
`release/latest.json` из ветки `main` и, если там версия новее установленной,
скачивает код из `main`. Поэтому после любого исправления:

1. Работать прямо в ветке `main` (без отдельных веток и pull request, если владелец не попросит иначе).
2. Поднять версию в `app/static/index.html`, строка `<div class="ver">`:
   `версия от <число месяц> (<номер+1>): <коротко, что нового>`.
3. Из корня репозитория запустить:
   `bash mac/release.sh "<что нового, одно-два предложения для владельца>"`
   — он пересоберёт `release/Avto-YouTube.zip` и перепишет `release/latest.json`.
4. Проверить синтаксис изменённых файлов (`python3 -m py_compile ...`).
5. Закоммитить всё одним коммитом с понятным русским сообщением и `git push origin main`.

Номер версии только растёт, по одному на каждый выпуск.
