АВТО ЮТУБ — ОПИСАНИЕ ПРОЕКТА
Версия от 20 октября 2026 (персонажи отдельно, голоса RU/EN, вкладки, сериалы, резервные копии)

Этот файл лежит на рабочем столе в папке «Авто ютуб — резерв». В нём записано, что это за программа,
что она умеет, как устроена и как всё восстановить. Если когда-нибудь придётся продолжать работу
с новым помощником (например, в новом чате с Claude), просто передайте ему этот файл целиком.


1. ЗАЧЕМ ЭТА ПРОГРАММА

Программа на Mac (M1), которая сама делает ролики для YouTube «без лица»:
тема → сценарий с хуками и проверкой редактора → озвучка → картинки (и при желании анимация) →
монтаж с музыкой, эффектами и субтитрами → обложка → загрузка на YouTube.
Работает у вас на компьютере как обычное приложение «Авто ютуб» (в Программах и в Доке), в своём окне.
Всё, что видит пользователь, на русском языке. Ролики можно делать на русском (СНГ) и на английском.


2. ЧТО ОНА УМЕЕТ

Сценарий
 - Придумывает 10 тем по нише проекта (или по вашей теме) и выбирает лучшую по оценкам.
 - Строит структуру: хук в первые секунды, повороты, «крючки» удержания каждые 60–90 секунд, открытые вопросы.
 - Пишет текст нужной длины и прогоняет через «редактора»: автоматический чек-лист и до нескольких кругов правок.
 - Галочка «Выбирать тему вручную»: программа предлагает темы (5 лучших сверху, остальные по кнопке),
   вы отмечаете одну и нажимаете «Взять эту тему». Сменить тему можно и позже, тогда ролик делается заново.
 - Галочка «Ручная правка текста»: программа останавливается сразу после проверки редактором,
   до сцен, картинок и озвучки. Можно исправить текст и нажать «Продолжить».
 - Шортсы пишутся по своим правилам: хук в первую секунду, ухудшение ситуации, неожиданный поворот
   и сильная последняя фраза. Предсказуемые сюжеты-«рекламы» отбраковываются.
 - Для шортсов 10 тем оценивает «строгий зритель»: зацепит ли первая фраза, можно ли угадать концовку,
   сработает ли поворот. Снимается та тема, которую он досмотрел бы до конца.
 - Новые темы не повторяют ситуации прошлых роликов проекта.
 - В проекте есть поле «Образцы удачных шортсов»: вставьте тексты понравившихся роликов,
   сценарист будет равняться на их уровень, не копируя сюжеты.
 - Название, описание, теги, перевод на русский для контроля.

Проекты и ниши
 - Проект = ниша с готовыми настройками: язык, стиль картинок, голос, формат, длительность, эффекты,
   анимация, субтитры, канал YouTube. Выбирается одной кнопкой при запуске ролика.
 - Ролики разделены по проектам (вкладки в списке роликов).
 - Готовые ниши: История, Мистика, Тру-крайм, Спорт, Космос, Биографии, Мифы, Психология,
   Разрушитель мифов, Детские мультики, Взрослые мультики (у многих есть английская и СНГ версия).
 - Свой проект можно сохранить как нишу (кнопка «⭐ Сохранить как свою нишу»): он появится в списке ниш
   с пометкой «моя ниша», из него быстро делаются новые проекты с теми же настройками.
 - Ненужные ниши убираются крестиком: готовые скрываются (вернуть — «Скрытые ниши» внизу списка),
   свои удаляются. Проекты при этом не трогаются.
 - Галочки проекта: «Ролики для детей» (добрый тон + отметка YouTube «для детей»),
   «Выдуманные истории» (сюжеты придумываются, а не берутся из реальных событий).

Пауза перед анимацией (с версии 45)
 - Галочка «Пауза перед анимацией: я сам выберу сцены» в «Новом ролике» и в проекте. Когда картинки и озвучка
   готовы, ролик останавливается («Ждёт вашей проверки»), в шаге «Анимация сцен» уже отмечены сцены, которые
   программа оживила бы сама. Можно добавить любые или снять, потом «Оживить выбранные и продолжить»
   (перед оплатой покажется цена) или «Без анимации, продолжить».
 - Картинки для шортсов: в описание добавлен запрет полей и рамок; белые поля по краям обрезаются сами,
   а если картинка по образцам вышла горизонтальной, она один раз перерисовывается вертикально.

Скорость готового ролика (с версии 44)
 - На странице ролика под видео и под шортсом есть «Скорость»: можно ускорить готовый ролик в 1.05–1.5 раза.
   Картинка и голос ускоряются вместе, голос не становится писклявым, субтитры .srt сдвигаются тоже.
   Оригинал сохраняется, «Обычная (оригинал)» возвращает его. При пересборке видео скорость применяется снова.
   Если ролик уже выложен, на YouTube и в Instagram останется старая версия.

Instagram (с версии 42)
 - Подключается без страницы Facebook: маркер со страницы «Настройка API для входа в Instagram»
   (кнопка «Сгенерировать маркер») вставляется в Настройки → Instagram. Маркер живёт 60 дней,
   программа сама продлевает его при выкладке. Старый способ через Graph API Explorer тоже работает.

Предметы (с версии 41)
 - Раздел «Предметы» слева: товары и вещи, которые должны выглядеть в кадре точно как на фото
   (рекламируемый продукт, фирменная кружка ведущего, машина героя). Загружается главное фото и до 8 фото
   с разных сторон, программа сама составляет по ним точное английское описание.
 - При запуске ролика предметы выбираются кнопками «Предметы в ролике», в проекте отмечаются предметы
   по умолчанию. Сценарий находит им место в истории, а сцены, где предмет виден, рисуются по его фото
   (fal.ai, лист с фото предмета идёт в нейросеть вместе с портретами персонажей и образцом места).

Персонажи
 - Отдельный раздел «Персонажи» слева: общая библиотека героев для всех проектов. Описание по-русски,
   программа сама составляет английское описание внешности. Портрет можно нарисовать (fal.ai) в одном из
   16 стилей картинок (реалистичное фото, 2D/3D-мультфильм, аниме, взрослый мультик, комикс, гравюра…)
   или загрузить свой. Персонажи хранятся всегда.
 - К персонажу можно загрузить до 8 фото с разных сторон (спина, профиль, детали). Для картинок они
   складываются в один лист-подсказку на персонажа, чтобы нейросеть рисовала его одинаково со всех сторон.
   Любое фото можно сделать главным портретом (★) или удалить (×).
 - Внешность персонажа нейросеть описывает строго по загруженным фото (ничего не придумывает: если ног не
   видно, про обувь не пишет). Кнопка «Описать внешность по фото» обновляет описание после новых фото.
 - Поле «Дополнения для сцен»: другая одежда и детали для некоторых сцен (например, «зимой — куртка»),
   основная внешность при этом не меняется.
 - В проекте отмечаются «персонажи проекта» — они выбираются сами при запуске ролика этого проекта.
 - При запуске ролика герои выбираются кнопками-иконками (любые из библиотеки). Сценарий строится вокруг них,
   на картинках они похожи на портрет (картинки с опорой на портрет через fal.ai, ~$0.04 за штуку).
 - У персонажа может быть свой голос ElevenLabs. Тогда сценарий пишет ему реплики отдельными строками
   «Имя: реплика», и каждая реплика озвучивается голосом этого персонажа, а остальное — рассказчиком.
   В проекте поле «Как звучат персонажи»: рассказчик + реплики / мультик (в основном диалоги) / только рассказчик.
 - В выдуманных историях они главные герои, в реальных — рассказчики/ведущие.

Сериал
 - В проекте можно включить «Это сериал». Пишется библия сериала (мир, правила, герои, главный вопрос сезона)
   и план сезона (одна строка — одна серия). Кнопка «Придумать библию и план сезона» делает черновик сама.
 - Каждый ролик получает номер серии. После сценария программа записывает, что произошло в серии,
   какие вопросы остались и чем она закончилась. Следующая серия это читает: продолжает сюжет,
   после хука делает короткое «в прошлой серии», в конце оставляет крючок на следующую.
 - В «Новом ролике» при выборе проекта-сериала видно, какой серией станет ролик и какая строка плана возьмётся.
 - Неудачную серию можно «забыть», чтобы следующие на неё не опирались.

Озвучка
 - ElevenLabs, выбор голоса из списка или вставка ID голоса вручную, свой голос у проекта.
 - Голоса разделены на «для русской аудитории» и «для английской». Программа определяет сама
   (по языку голоса в ElevenLabs; стандартные голоса George, Brian и др. — английские), пометку можно
   поменять в Настройках → Озвучка. Русские голоса добавляются на elevenlabs.io: Voice Library →
   Language: Russian → Add to my voices.
 - Голоса делятся на мужские, женские и детские, у каждого подписана страна акцента (США, Великобритания,
   Россия и СНГ…) и описание по-русски. В Настройках → Озвучка есть фильтры по аудитории, типу и стране.
 - В проекте с форматом «Только шортс» настройки показываются под шортс, есть кнопка «Под шортс» для озвучки
   (стабильность 0.35, выразительность 0.35, скорость 1.08).
 - Для русского: модель eleven_multilingual_v2, стабильность 0.45, похожесть 0.8, выразительность 0.15, скорость 1.0.
 - Ключ ElevenLabs должен иметь права Voices: Read и User: Read, иначе список голосов не загрузится.

Картинки и анимация
 - Несколько дешёвых сервисов картинок на выбор (по тому, какой ключ вставлен), готовые стили.
 - Кадр показывает то место и время, о котором говорит диктор: «зима, Ленинград 1941» рисуется как
   суровый зимний Ленинград тех лет. Примеры, факты из истории и сравнения получают свои места, ролик
   не стоит в одной комнате.
 - Каждое место выглядит одинаково во всех своих кадрах (галочка в проекте, включена по умолчанию):
   сначала рисуется каждое место действия без людей, и все сцены там рисуются по этому образцу.
   Сцена знает своё место (видно в шаге «Сцены» со значком 📍).
 - Разные ракурсы: программа сама расписывает камеру для каждой сцены (общий план, средний, крупный,
   от первого лица, из-за плеча, деталь, снизу, сверху, в профиль). Соседние кадры никогда не повторяют
   ракурс, даже в одной комнате. Ракурс виден в шаге «Сцены» со значком 🎥.
 - Плавное движение камеры по картинке (эффект Кена Бёрнса).
 - Анимация сцен через fal.ai: выключена / первые сцены (хук) / начало и ключевые моменты /
   выбранные вручную сцены / все сцены. Количество сцен задаётся числом (по умолчанию 3).
   На странице ролика можно отметить галочками конкретные сцены для оживления.
   Каждый клип оплачивается минимум за 5 секунд, даже если сцена длится 1–2 секунды.
   Модели: Kling 2.5 Turbo Pro (рекомендуется, ~$0.07 за секунду клипа = ~$0.35 за сцену), Kling 2.6, LTX-2 (дешевле).
   В настройках есть кнопка «Проверить анимацию» (~$0.4).
   Анимация всегда выключена по умолчанию. Перед тем как оживить сцены в готовом ролике, программа
   показывает, сколько новых сцен будет оживлено и сколько это стоит, и спрашивает подтверждение.
   Уже оживлённые сцены хранятся и повторно не оплачиваются. В шапке ролика видно, сколько ушло
   на картинки, анимацию и текст.

Статистика и обучение
 - После подключения канала программа раз в 6 часов собирает статистику роликов: просмотры,
   досмотры, среднее время просмотра, подписки. Для этого в Google Cloud нужно включить
   YouTube Analytics API (шаг описан в Настройках). Ролик, загруженный вручную, можно привязать ссылкой.
 - Когда в проекте набирается 10 роликов старше 3 дней, ИИ сравнивает удачные и неудачные
   и записывает правила «что работает». У каждого проекта (ниши) свои правила.
   Их видно в редакторе проекта, любое правило можно выключить. Новые сценарии пишутся с учётом правил.

Монтаж
 - Видео 1920×1080 и вертикальный шортс 1080×1920. Режим «Только шортс»: длина шортса задаётся
   в секундах (15–180), превью тоже вертикальное.
 - Музыка: по умолчанию берётся трек из раздела «Музыка», подходящий по стилю к настроению ролика
   (у каждого трека можно подписать стиль). Для отдельного ролика можно включить «Сочинять новую»:
   программа сочинит инструментальную музыку через ElevenLabs Music (~$0.30 за минуту; для длинного
   ролика трек 2,5 минуты повторяется по кругу) и сохранит её в «Музыку» с подписью стиля для повторного
   использования. Если сочинить не получилось, берётся трек из раздела. Громкость выравнивается.
 - Текст для озвучки можно исправить вручную: шаг «Проверка редактором» → «Итоговый текст для озвучки» →
   «Сохранить мой текст». Сцены, картинки, озвучка и видео делаются заново по вашему тексту.
 - Редактор проверяет сценарий «на слух»: пересказывает историю одной фразой; рубленый текст
   (в среднем меньше 6,5 слова в предложении) не принимается и переписывается.
 - Шаблоны сценария: в папке prompts хранятся только шаблоны, которые вы меняли сами. Остальные берутся
   из программы, поэтому улучшения новых версий доходят автоматически.
 - Озвучка: режим «Герой-ведущий» — весь ролик рассказывает главный герой своим голосом. ИИ пишет только
   текст для озвучки, без ремарок и описаний кадров.
 - Эффекты по сценарию: резкие наезды, отъезды, тряска камеры, звуки «вжух», «удар», «перелистывание».
   Режимы: выключены / мягко / ярко. Свои звуки можно положить в ~/AutoYouTube/data/sfx/<whoosh|impact|swoosh>/.
 - Субтитры (включаются отдельно для видео и для шортса), крупные слова в шортсах, файл .srt для YouTube.
 - Обложка с крупным текстом.

YouTube
 - Подключение нескольких каналов, загрузка видео и шортса, язык ролика, отметка «для детей».

Instagram
 - Вертикальные ролики выкладываются рилсами с подписью (название, первый абзац описания, до 8 хэштегов).
 - Подключение один раз: Настройки → «6. Instagram» (профессиональный аккаунт, привязанный к странице
   Facebook, приложение на developers.facebook.com, токен из Graph API Explorer). Инструкция внутри.
 - Кнопка «📸 Выложить в Instagram» на странице ролика или автовыкладка, как только ролик готов.
 - Видео идёт прямо с Мака в Instagram. В России при выкладке нужен включённый VPN.

Удобство
 - Оформление: светлое в стиле macOS и тёмное. Переключатель слева внизу: «Авто» (днём светлое, вечером
   тёмное, вместе с темой Mac), «Светлая», «Тёмная». Выбор запоминается.
 - Вкладки сверху: последние открытые страницы (ролики, проекты, настройки), закрываются крестиком,
   рядом кнопка «＋ Новый ролик».
 - Всё, что вписано и ещё не сохранено (новый ролик, проект, настройки, персонаж, шаблон), запоминается
   само: можно уйти на другую вкладку и вернуться. Сверху появится напоминание сохранить и кнопка
   «Отменить изменения».
 - Нажатие на нишу в «Новый проект» открывает уже существующий проект этой ниши, а не создаёт копию.
   Лишние проекты удаляются крестиком на карточке.

Очередь
 - Можно поставить сразу несколько роликов. Очередь переживает выключение Мака:
   после запуска программа продолжает с того шага, где остановилась.
 - Любой шаг можно переделать, любую картинку перерисовать.


3. КЛЮЧИ И СЕРВИСЫ (вставляются только в Настройках программы)
 - Anthropic (Claude) или OpenAI — сценарий.
 - ElevenLabs — озвучка.
 - fal.ai — картинки, анимация, картинки с персонажами (также поддерживаются другие сервисы картинок).
 - Google (client_secret.json) — загрузка на YouTube.
 - Meta (App ID, App Secret, токен) — выкладка в Instagram; App Secret не сохраняется.
Русские голоса: кнопка «🇷🇺 Подобрать русский голос» в Настройках и в проекте открывает голоса носителей
русского из библиотеки ElevenLabs (фильтры: пол, для чего, поиск; ▶ послушать). «Выбрать» сама добавляет
голос в ваш аккаунт ElevenLabs и ставит его, остаётся нажать «Сохранить».
Балансы: раздел «💰 Балансы» и строчки слева внизу. ElevenLabs (символы) и fal.ai (доллары) присылают
точный остаток сами. Anthropic и OpenAI баланс программам не сообщают: впишите остаток из кабинета,
и программа будет вычитать свои траты (примерно, сверяйте раз в неделю). Мало денег выделено красным.
Ключи хранятся только у вас на Маке в ~/AutoYouTube/data/settings.json. Никому их не пересылайте.


4. ГДЕ ЧТО ЛЕЖИТ
 - Программа: ~/AutoYouTube
 - Ваши данные: ~/AutoYouTube/data
     settings.json — настройки и ключи
     projects/     — проекты и серии сериалов
     characters/   — персонажи с портретами
     prompts/      — шаблоны сценариев (если вы их меняли)
     youtube/      — подключённые каналы
     music/, sfx/  — музыка и звуки
     jobs/         — сами ролики (большие файлы, в резервную копию не входят)
 - Резервные копии и этот файл: рабочий стол → папка «Авто ютуб — резерв».


5. РЕЗЕРВНЫЕ КОПИИ И ВОССТАНОВЛЕНИЕ
 - Копия делается сама при каждой установке/обновлении, а ещё вручную:
   кнопкой в программе (Настройки → «Резервная копия») или двойным щелчком по
   «Сделать резервную копию.command» в папке «Авто ютуб — резерв».
 - В копию входят настройки, ключи, проекты, персонажи, серии, шаблоны, каналы, музыка и звуки.
   Хранятся последние 15 копий.
 - Восстановить: двойной щелчок по «Восстановить из копии.command», выбрать номер копии.
   Перед восстановлением текущее состояние тоже сохраняется в копию, так что потерять ничего нельзя.
 - В папке также лежит «Авто ютуб (программа).zip» — сама программа.

Если Мак новый или всё удалено:
 1) Скопируйте папку «Авто ютуб — резерв» на рабочий стол нового Мака.
 2) Распакуйте «Авто ютуб (программа).zip», перетащите «Авто ютуб» в «Программы» и запустите
    (первый раз: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»).
 3) Закройте программу (кнопка «Выключить программу» слева внизу),
    дважды щёлкните «Восстановить из копии.command», выберите копию, снова запустите «Авто ютуб».


6. КАК ОБНОВЛЯТЬ
 Когда выходит новая версия, слева вверху появляется зелёная кнопка «Обновить до версии …».
 Нажмите её: программа скачает новую версию, закроется и через полминуты откроется уже новой.
 Перед обновлением она сама делает резервную копию настроек.
 Скачать программу заново (для друзей): https://raw.githubusercontent.com/Omajati/avto-youtube/main/release/Avto-YouTube.zip
 Ваши данные (~/AutoYouTube/data) при обновлении не трогаются. Версия видна в программе слева внизу.


7. ДЛЯ РАЗРАБОТЧИКА (если продолжать в новом чате)
 - Backend: Python 3.12, FastAPI + uvicorn на 127.0.0.1:8765, SQLite-очередь (data/jobs.db),
   каждый шаг ролика сохраняет результат в data/jobs/<id>/<шаг>.json и продолжается с места остановки.
 - Frontend: один app/static/app.js без сборки, хэш-маршруты, весь текст на русском.
 - Шаги: idea → outline → script → review → scenes → extras → short_script → approval → voice →
   images → animate → video → short_video (обложка и загрузка на YouTube идут после готового видео).
 - LLM: строгие JSON-схемы; системный промпт = prompts/00_system.txt + блоки-«переопределения» из кода
   (язык RU, шортс, детский, выдуманные истории, персонажи, сериал).
 - Озвучка: ElevenLabs /with-timestamps, тайминги слов идут в субтитры (ASS через libass).
 - Анимация: очередь fal.ai (Kling / LTX). Эффекты и звуки собираются в FFmpeg/Python.
 - Файлы: app/pipeline.py (шаги), server.py (API), projects.py (проекты, персонажи, предметы, серии),
   animate.py, effects.py, captions.py, media.py, tts.py, images.py, youtube.py, instagram.py, uploader.py, balance.py, backup.py.
 - Приложение: mac/build.sh собирает «Авто ютуб.app» (скрипт mac/launch + программа внутри
   Contents/Resources/payload). При запуске, если версия в payload/VERSION новее ~/AutoYouTube/VERSION,
   mac/setup.sh ставит программу в ~/AutoYouTube (uv, Python 3.12, библиотеки), потом
   run.py --window открывает своё окно (pywebview, системный WebKit); без него — браузер.
   Номер версии берётся из подписи «версия от … (N)» в app/static/index.html.
 - Обновления: код лежит на GitHub (Omajati/avto-youtube, ветка main). app/updater.py читает
   release/latest.json, скачивает main архивом, заменяет app, prompts_default, run.py и т.д. в ~/AutoYouTube,
   ставит библиотеки (uv), обновляет копию внутри «Авто ютуб.app» и перезапускает её.
   Выпуск: поднять номер в подписи версии, bash mac/release.sh "что нового", git commit, git push.
 - Пожелания владельца: всё на русском, простые объяснения, при каждой новой версии давать шаги обновления.
