# Авто ютуб

Программа для Mac, которая сама делает видео для YouTube: тема → сценарий с хуками и проверкой редактором → озвучка ElevenLabs → картинки → видео 1920×1080 и вертикальный шортс.

## Установка (один раз)

1. Скачайте [Avto-YouTube.zip](https://raw.githubusercontent.com/Omajati/avto-youtube/main/release/Avto-YouTube.zip). Двойной щелчок распакует архив.
2. Перетащите «Авто ютуб» в папку «Программы» и запустите.
3. Первый раз Mac скажет, что не может проверить разработчика: нажмите «Готово», откройте Системные настройки → Конфиденциальность и безопасность и внизу нажмите «Всё равно открыть».
4. При первом запуске программа сама доустановит всё нужное (1–3 минуты) и откроет своё окно.

Ключи сервисов (Claude, ElevenLabs, fal.ai) каждый вписывает свои в «Настройках».

## Обновление

Когда выходит новая версия, слева вверху в программе появляется зелёная кнопка «Обновить». Один щелчок, и через полминуты программа откроется уже новой. Ролики, настройки и ключи сохраняются.

## Где что лежит

- Программа: `~/AutoYouTube`
- Ролики, настройки, музыка, шаблоны: `~/AutoYouTube/data`
