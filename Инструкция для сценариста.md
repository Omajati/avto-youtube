# Сценарист → Авто ютуб: как сдавать готовые сценарии

Скопируйте этот файл в репозиторий сценариев под именем `CLAUDE.md` — тогда каждый новый чат сценариста
будет сдавать работу правильно сам.

## Куда класть

Каждый готовый проект — один `.zip` в папке своего канала (ниши) в корне этого репозитория:

```
Семейные драмы ES/20_НАЗВАНИЕ.zip
Истории RU/05_НАЗВАНИЕ.zip
```

- Имя папки канала пишется всегда одинаково, до буквы (программа по нему раскладывает проекты на Mac).
- Имя архива = имя проекта: номер и короткое название, например `20_НАСЛЕДСТВО.zip`. У каждого проекта
  новое имя — проект с уже бывшим именем программа не возьмёт («уже есть»).
- Глубже папки канала архивы не класть, папки с именем на «_» программа пропускает.

## Что внутри архива

Одна папка с именем проекта, в ней файлы (язык — код в имени: EN, RU, DE или ES):

```
20_НАСЛЕДСТВО/
  озвучка_ES.txt            текст диктора
  сцены_генерация.txt       REFERENCE R1… и SCENE S001…
  превью_ES.txt
  загрузка_YouTube_ES.md    название, описание, теги
```

Собрать архив (из папки, где лежит папка проекта):

```bash
python3 -c "import shutil,sys; shutil.make_archive(sys.argv[1], 'zip', '.', sys.argv[1])" 20_НАСЛЕДСТВО
mv 20_НАСЛЕДСТВО.zip "Семейные драмы ES/"
```

## Как сдать

1. Положить архив в папку канала, папку проекта в репозиторий не добавлять (только `.zip`).
2. Закоммитить и отправить прямо в ветку `main`:
   `git add "Семейные драмы ES/20_НАСЛЕДСТВО.zip" && git commit -m "Сценарий: 20_НАСЛЕДСТВО" && git push origin main`
3. Уже отправленные архивы не менять и не удалять: исправленная версия — новый архив с новым именем.

Программа «Авто ютуб» на Mac проверяет репозиторий раз в 2 минуты, скачивает новые архивы и ставит
проекты в очередь на монтаж.
